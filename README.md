# GTDOA

Gujarat Transport Drivers Owners Association — Next.js foundation.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

This repository is ready to import into Vercel as a Next.js application. No environment variables are required for the current public landing page.
